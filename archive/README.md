# Archivo histórico

Estos archivos se conservan para trazabilidad de importaciones y auditorías antiguas. No forman parte del build ni de los scripts vigentes.

- `legacy-tools/`: utilidades puntuales reemplazadas por los scripts de `scripts/`.
- `legacy-import-artifacts/`: volcados y textos intermedios usados para importar bancos anteriores.

Los comandos mantenidos están documentados en el README principal y en `package.json`.
